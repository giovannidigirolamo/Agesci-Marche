# Download APK

1. Copia qui il file generato dalla build Android con il nome `agesci-marche.apk`.
2. Apri `apk-info.json` e imposta `"available": true`.
3. Pubblica il sito: il pulsante nel profilo utente abilita automaticamente il download.

Il file APK è il pacchetto di installazione Android, non una scorciatoia del browser.
